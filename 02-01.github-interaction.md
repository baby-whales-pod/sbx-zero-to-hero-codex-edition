# GitHub interaction
> `sbx` without ai governance policy

> [!NOTE]
> In this lesson you will have the agent scaffold a small Go microservice, publish its port to your host to test it, then commit & push the code and open a GitHub issue — all from inside the sandbox.

## Create a simple application

Return to your sbx codex session:

Try this:

```raw
What is the golang version?
```

Then:

```raw
- Create a golang microservice 
- Add one endpoint that return a hello world message in json
- Start the program, listening on 5050
```

- Look at the code
- Try to run `curl http://localhost:5050/hello` in another terminal

> You should get this message:
> ```bash
> curl: (7) Failed to connect to localhost port 5050 after 0 ms: Could not connect to server
> ```

### Publish port

Open another terminal:

```bash
# get the list of the published ports
sbx ports codex-hello-sbx 

# publish the port
sbx ports codex-hello-sbx --publish 5050:5050/tcp
```

The try again to run `curl http://localhost:5050/hello`

> You should get this message:
> ```bash
> {"message":"Hello, World!"}
> ```

To unpublish the port:
```bash
sbx ports codex-hello-sbx --unpublish 5050:5050/tcp
```

### Stop the application

Go back to the agent and ask:

```
- stop the microservice
- run `ps -d`
```

## Commit the source code

> ✋ **GitHub authentication.** `git push` from inside the sandbox works because the proxy injects your GitHub token — make sure you injected a GitHub PAT during setup (see [`00-00.requirements.md`](./00-00.requirements.md#inject-a-github-token-pat)).

Ask the agent this:

```
commit and push all the code
```

Check on [https://github.com/k33g/hello-sbx](https://github.com/k33g/hello-sbx)
> ✋ replace `k33g` by your GitHub handle

## Create an issue

Codex can drive the `gh` CLI (calls to `api.github.com` are authenticated by the same injected GitHub token). Ask the agent this:

```
Using the gh CLI, create an issue with a story about Jean-Luc Picard and the Borg Queen
```
> 🖖 you can use your own references, nothing is mandatory 🤓

Check on [https://github.com/k33g/hello-sbx](https://github.com/k33g/hello-sbx)
> ✋ replace `k33g` by your GitHub handle
