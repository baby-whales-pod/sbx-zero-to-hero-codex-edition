# Snapshots & templates
> `sbx` without ai governance policy

> [!NOTE]
> In this lesson you will install a tool in a sandbox, freeze that prepared state into a reusable template image with `sbx template save`, then create a new sandbox from it that starts already set up — no install step.

A **snapshot** freezes the current state of a sandbox — installed tools, packages, files — into a reusable **template image**. New sandboxes created from that template start *already prepared*, with no install step.

> Kit vs snapshot:
> - a **kit** is *declarative* and re-applied on every run (`05-01`)
> - a **snapshot** is a *baked image* of a sandbox at a point in time
>
> Command: `sbx template save SANDBOX TAG` → reuse with `sbx run -t TAG AGENT`.

## 1. Prepare a sandbox with something installed

Create a sandbox and install a tool inside it (do it the "manual" way here, so the snapshot has something to capture):

```bash
sbx run codex . --name codex-tosnap
```

Install a tool from a second terminal:

```bash
sbx exec -u 0 codex-tosnap -- sh -c 'apt-get update -qq && apt-get install -y --no-install-recommends figlet'
# verify
sbx exec codex-tosnap -- figlet "ready"
```
> ✋✋✋ or ask the agent to install something

## 2. Save the snapshot as a template

```bash
sbx template save codex-tosnap my-snapshot:v1
```
> Sandbox codex-tosnap is running and must be stopped before saving. Stop it now? (y/N): y

List your templates:

```bash
sbx template ls
```

## 3. Create a new sandbox from the snapshot

Use `-t` (`--template`) to start a fresh sandbox from the baked image:

```bash
sbx run codex . -t my-snapshot:v1 --name codex-fromsnap
```

The tool is **already there** — no reinstall:

Ask the agent:
```text
please run: figlet "hello from a snapshot"
```

## 4. Export and load on another host

A snapshot can be exported to a tar file and loaded elsewhere:

```bash
# export while saving
sbx template save codex-tosnap my-snapshot:v1 --output /tmp/my-snapshot.tar

# on another machine (or after `sbx template rm`)
sbx template load /tmp/my-snapshot.tar
```

## 5. Cleanup

```bash
# remove the sandboxes
sbx rm codex-tosnap codex-fromsnap

# remove the template image
sbx template rm my-snapshot:v1

# remove the exported tar
rm -f /tmp/my-snapshot.tar
```

## 6. When to use what

| You want to…                                            | Use          |
|---------------------------------------------------------|--------------|
| Version & share a *recipe* of tools/config, re-applied  | **kit**      |
| Start instantly from an already-prepared environment    | **snapshot** |
